# Project 1: Secure data lake foundation

Builds the foundation for Nova Retail: ADLS Gen2 (bronze/silver/gold), Key Vault,
a managed identity, then private endpoints and private DNS.

- `main.bicep`, `main.bicepparam`: infrastructure as code
- Parts: 1A portal build, 1B Bicep, 1C network lockdown, 1D identity and policy, 1E break/document/teardown

Deploy notes and ADRs are added as each part is completed.
